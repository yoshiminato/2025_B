## 📁 プロジェクト構成

```
lib/
├── main.dart             # エントリーポイント
├── app.dart              # アプリケーション設定
├── global.dart           # グローバル設定
├── firebase_options.dart # Firebase設定
├── error_handle.dart     # エラーハンドリング
├── models/               # データモデル
├── screens/              # 画面コンポーネント
├── widgets/              # 再利用可能なウィジェット
├── routers/              # ルーティング設定
├── services/             # サービスロジック(認証・データベース・cloud function...)
└── states/               # 状態管理（Riverpod）
```
